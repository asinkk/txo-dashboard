計算方式
合成期貨
取買權與賣權中價最接近的履約價 K，F = K + C − P。
預期波動
價平買權加賣權（跨式）價格。
IV
Black-76 模型、到期日 13:30 為終點，用即時買賣中價反推；夜盤點差較寬，單點可能有雜訊。
P/C ratio
賣權除以買權。未平倉量用最近日盤收盤數字；成交量 P/C 用即時盤累計。
最大痛點
以收盤未平倉量計算，所有買方部位價值總和最小的結算價。
未平倉牆
合成期貨 ±3,000 點內 OI 最大的買權和賣權履約價。
OI 增減
期交所每日行情，今天日盤收盤 OI 減前一交易日。
法人與大額交易人
期交所「三大法人：選擇權買賣權分計」與「大額交易人未沖銷部位」，每日盤後公布。
正逆價差
台指期近月減加權指數，日盤才計算；正值為正價差。
VIX 位置
期交所台指 VIX 日收盤，在可取得期間內的區間位置（IV Rank = (今 − 最低)/(最高 − 最低)）與百分位。期交所只提供近 3 個月，之後每天累積，滿一年就是一年區間。
HV
加權指數日報酬 20 日標準差年化。ATM IV 除以 HV 大於 1 代表選擇權比實際波動貴。
